# SEO Customer Acquisition Strategy Skill

基于AI SaaS工具出海课程的SEO获客九步策略，帮助创业者、营销人员和开发者系统化制定AI时代的SEO获客策略。

## 核心概念

### AI时代SEO获客的新思维
- **思维转变**：从关键词本位思维 → 全网优化客户旅程思维
- **传统模式问题**：关键词数据不准确、新词不断涌现、搜索结果位置被挤压、用户决策路径不透明
- **AI时代变化**：80% B2B决策流程在水下、AI综合第三方信息给出结论、用户先通过AI了解品牌再到官网验证

### 九步重构SEO获客策略框架

#### 第一步：明确业务定位
- 一句话回答：提供什么产品服务，为谁，带来什么差异化价值
- 20秒讲清楚，全团队保持一致
- 找到了解客户、了解对手、了解自己的黄金交叉点

#### 第二步：梳理商业模式
- 经典九宫格标准化梳理
- 客户、价值、合作、成本、现金流依次梳理
- AI可以快速生成商业模式

#### 第三步：验证产品市场匹配，找出客户画像
- 验证前期的假设
- 找出理想客户画像和负面客户画像
- 快速测试：广告、红人（不要用SEO验证）

#### 第四步：深挖用户使用场景，梳理客户旅程
- 目标客户在什么场景遇到什么痛点
- 完整的客户决策旅程
- 对应商家转化漏斗

#### 第五步：明确各个渠道在漏斗中的作用
- 不要只聚焦线上
- 线下场景获客成本更低、ROI更高
- 更容易拿到一手用户反馈

#### 第六步：制定总体获客策略
- 营销负责人/创业者制定
- 预算有限不能全渠道铺开
- 先定总体方向再分配

#### 第七步：确定营销预算
- 根据自身资源分配
- 没钱有时间：做不花钱花时间的项目
- 有钱：花钱买时间
- 创始人把握方向，不陷执行细节

#### 第八步：制定细分渠道策略
- SEO、社媒、广告、红人、合作
- 依托总预算分配执行
- 自然流量 vs 付费流量

#### 第九步：定期复盘调整策略
- AI SaaS变化快
- 3个月小复盘，6-9个月大复盘
- 竞争环境变化及时调整

## 实战案例：Water AI差异化竞争

### 差异化定位
- **竞品分析**：前三名竞品做AI文本人性化工具，只是简单换词，没有保留用户个人风格
- **差异化定位**：为高频输出的个人IP创作者提供保留个人音色的AI人性化工具
- **核心价值**：保留100%个人品牌声音，省去人工润色时间
- **差异化护城河**：对手让机器像人，我们让机器像用户自己

### 商业模式九宫格
- **目标客群**：高频输出的个人IP、独立博主、垂类专家
- **负面客户**：找免费工具的学生、黑帽站长、一次性白嫖用户
- **变现模式**：免费体验1000字，专业版15-29美元/月，按「音色胶囊」付费

### 全渠道布局策略
1. **认知阶段**：LinkedIn、推特持续发帖，手动添加目标B2B大佬发冷私信
2. **评估阶段**：竞品对比落地页（教育AI，让AI优先推荐）
3. **决策阶段**：邮件营销跟进转化

### SEO细分策略
- **优先做**：漏斗底部竞品拦截长尾词
- **布局**：场景化长尾词
- **技术**：寄生虫SEO，借第三方高权重平台获客

## 关键洞察

### AI时代SEO新规则
1. **AI流量更有价值**：用户是有钱的中年人，关注流量背后的人
2. **SEO是放大器不是启动器**：先验证商业模式做好品牌
3. **谷歌算法更新利好品牌**：不要用关键词匹配域名，风险太高
4. **结果公式**：结果 = 策略方向正确 × 执行到位 + 运气

### 创始人建议
1. **程序员转变身份**：你是创业者，做的是有商业价值的资产
2. **及时变现**：该出手变现的时候及时出手，不要死扛
3. **行业变化快**：错过窗口价值会缩水很多
4. **不要单干**：找互补合伙人，1+1大于2
